# Butter Visa Assessment

## 本地启动

### 环境要求

- Node.js 18 或更高版本
- npm

### 安装依赖

```bash
npm install
```

### 启动开发服务

```bash
npm run dev
```

开发服务默认运行在：

```text
http://localhost:3000
```

## 常用命令

```bash
npm run dev      # 启动本地开发服务
npm run build    # 构建生产版本
npm run preview  # 本地预览构建结果
npm run lint     # TypeScript 类型检查
```
